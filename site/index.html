What's inside

Everything it takes to make a JPEG smaller, in one crate that builds for wasm32-unknown-unknown as it is.

An encoder that searches

Trellis quantization decides every coefficient against its real bit cost. Huffman tables and progressive scans are optimized per image. Gray, RGB and CMYK; 4:4:4 and 4:2:0.

Lossless re-coding

optimize_jpeg shrinks an existing JPEG without changing a pixel. strip_metadata removes EXIF, GPS and XMP the same way, keeping orientation and the color profile.

Read, crop, resize

A decoder for baseline and progressive files, EXIF orientation, cropping, and Lanczos3 resizing with a linear-light option that keeps fine detail from darkening.

Built for untrusted input

Malformed files return None instead of panicking. Pixel and scan limits are checked before anything is allocated, and the JPEG parser is fuzzed weekly in CI.

Use it in your code

The same encoder ships as a Rust crate and as an npm package.

Rust

cargo add smallpeg

Rust 1.88 or later. No dependencies, and it builds for wasm32-unknown-unknown as is. API documentation is on docs.rs, and the guide covers resizing, optimizing, color profiles and untrusted input.

// rgb: width * height * 3 bytes, interleaved
let jpeg: Vec<u8> = smallpeg::Encoder::new(80).encode_rgb(&rgb, width, height);

// full-resolution color, for screenshots and documents
let jpeg = smallpeg::Encoder::new(85)
    .sampling(smallpeg::Sampling::S444)
    .encode_rgb(&rgb, width, height);
// turn it upright, fit it in 1600 px, write a new JPEG without the EXIF
fn shrink(photo: &[u8]) -> Option<Vec<u8>> {
    let info = smallpeg::jpeg_info(photo)?;
    let img = smallpeg::decode_jpeg(photo)?;
    let (px, w, h) = smallpeg::apply_orientation(
        &img.pixels, img.width, img.height, img.channels as usize, info.orientation,
    );
    let (nw, nh) = smallpeg::fit_within(w, h, 1600, 1600);
    let enc = smallpeg::Encoder::new(80);
    Some(if img.channels == 1 {
        enc.encode_gray(&smallpeg::resize_gray_linear(&px, w, h, nw, nh), nw, nh)
    } else {
        enc.encode_rgb(&smallpeg::resize_rgb_linear(&px, w, h, nw, nh), nw, nh)
    })
}
// same pixels, fewer bytes
if let Some(opt) = smallpeg::optimize_jpeg(&jpeg) {
    if opt.len() < jpeg.len() { /* keep opt */ }
}

// drop EXIF, GPS and XMP; keep orientation and the ICC profile
let clean = smallpeg::strip_metadata(&jpeg);

JavaScript

npm install smallpeg

Node 22.12 or later, and current browsers through any bundler. One WebAssembly file of about 240 KB (90 KB compressed), no native binaries, TypeScript types included. The full API is in the JavaScript API documentation.

import { encode, optimize, stripMetadata } from "smallpeg";
import { readFileSync, writeFileSync } from "node:fs";

// data: width * height * channels bytes (1 gray, 3 RGB, 4 RGBA)
const jpeg = encode({ data: rgb, width, height }, { quality: 80 });

// same pixels, fewer bytes
const input = readFileSync("photo.jpg");
const smaller = optimize(input);
if (smaller && smaller.length < input.length) writeFileSync("photo.jpg", smaller);

// drop EXIF, GPS and XMP
const clean = stripMetadata(input);
import { init, encode } from "smallpeg/web";

await init(); // loads the .wasm file once

const jpeg = encode(ctx.getImageData(0, 0, w, h)); // RGBA, alpha onto white
const blob = new Blob([jpeg], { type: "image/jpeg" });
